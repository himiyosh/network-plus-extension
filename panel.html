Export network data

Sanitized output is the safe default.

Scope

Sanitized output redacts every URL query and form-like fragment value, both URL userinfo components, Cookie values, and every header value outside a small structural allowlist.

Full output bypasses those protections and can expose:
  • Authorization, proxy authorization, custom, security, trace, request-ID, and client-certificate headers
  • Cookie and Set-Cookie values
  • URL usernames, passwords, query values, and fragment values
  • Request and response bodies, including base64 content

This confirmation applies only to this action. Network+ does not save a full-output preference.

Edit and resend request

Send composes a new request from these fields, and the inspected page itself issues it — so cookies, CORS, and the page's security policies apply as usual. The reply arrives as a new captured row.

Browser-managed headers (Host, Cookie, Content-Length, Origin, Referer, and the Sec-* and Proxy-* families) are set by the browser and cannot be overridden here.

🪟 Keep DevTools open

Capture runs inside the original tab's DevTools — this tab is a live mirror of it.

⚠️ Closing DevTools stops capture and freezes this tab.

DevTools is docked, so both stay visible. Tidy it away with a one-time setup:

  1. Open the ⋮ menu at the top right of DevTools.
  2. Under "Dock side", choose "Undock into separate window".
Dock side

It is the highlighted icon — the first of the four.

✅ DevTools remembers this choice: every future pop-out then minimizes the DevTools window automatically while capture keeps running.
